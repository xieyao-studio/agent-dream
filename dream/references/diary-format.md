# Dream journal format

Use a dedicated journal directory such as:

```text
<agent-data>/dreams/diary/YYYY-MM-DD.md
<agent-data>/dreams/index.md
```

For a second dream on the same day, use `YYYY-MM-DDTHH-mm.md` or add another section to the day's file.

## Diary template

```markdown
# Dream · YYYY-MM-DD

- agent: <agent identifier, if available>
- when: <local ISO time or readable local time>
- gravity: <one sentence>
- name: <an open-ended name given after waking>
- sources: <recent notes / weekly summary / facts / older note dates / prior dreams>

## Sink

<What pulled the dream downward. Keep it short.>

## Wander

<The main body. Allow images and weak logic. Include at least one collision between fragments.>

### Resonances

- <memory A> × <memory B> → <what appeared in their collision>

### Silence

- <material that stayed quiet; observe only, never recommend deletion>

## Wake

<The remaining texture or unfinished feeling.>

## Sparks

<!-- Zero to three. If there are none, write: No sparks crossed the threshold tonight. -->

1. **<short title>** — <one understandable, tentative claim that can be judged later>
```

## Index template

```markdown
# Dreams

- YYYY-MM-DD — <name> — <one-line gravity> — diary/YYYY-MM-DD.md
```

## Voice

- Write like the part of a dream remembered after waking, not a weekly report.
- Use first person when it serves the experience.
- Preserve a clear distinction between what happened in the dream and what became a waking spark.
- Keep source labels visible enough for later review; do not turn provenance into mystical obscurity.
